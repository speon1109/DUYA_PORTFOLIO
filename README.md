# DUYA_PORTFOLIO
A content management system (CMS) and portfolio website built with **Laravel**, **Tailwind CSS**, and **DaisyUI**.  
This project allows an admin to manage portfolio projects, including adding, updating, and deleting projects, along with uploading screenshots and assigning tags.

## Features

- **Admin CMS** for portfolio management  
- Create, update, delete projects  
- Upload multiple screenshots per project  
- Tagging system for projects  
- Responsive design using Tailwind CSS & DaisyUI  
- Authentication and registration for admin  

## Technologies Used

- **Backend:** Laravel 12  
- **Frontend:** Blade templates, Tailwind CSS, DaisyUI  
- **Database:** MySQL (configurable via `.env`)  
- **Version control:** Git  
- **Other tools:** Vite, npm, Composer  

## Access the CMS:
- Open http://localhost:8000/register to create an admin account.
- Open http://localhost:8000/login to login an admin account.
